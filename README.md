A web-based application that recommends a car based on user preferences through a series of 10 questions. Built with HTML, JavaScript, Tailwind CSS, and styled with a modern, responsive design featuring a gradient background, glassmorphism effects, and smooth transitions.

## Features





Interactive Quiz: Answer 10 questions with 4 options each to receive a personalized car recommendation.



Modern Design: Includes a blue-to-purple gradient background, glassmorphism card, rounded buttons with hover animations, and emoji icons for options.



Responsive Layout: Optimized for both desktop and mobile devices with full-width buttons on smaller screens.



Progress Bar: Visual indicator of quiz progress.



Smooth Transitions: Fade effects when moving between questions.



Typography: Uses Poppins font with varied weights for a polished look.



Car Recommendations: Suggests one of five cars (Toyota Corolla, Honda CR-V, Jeep Wrangler, Tesla Model S, Toyota Sienna) with detailed reasoning based on user answers.
